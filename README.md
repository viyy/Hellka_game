# Хеллка — бесконечный платформер

Пиксельный раннер про милую чертовку: собирай кристаллы и монеты, прыгай по платформам над лавой, топчи бесов. Скорость растёт без конца, цель — максимум очков.

**Играть:** https://viyy.github.io/Hellka_game/

Работает в браузере на ПК и телефоне, ставится как PWA и играет офлайн.

## Управление

| Действие | Клавиши |
|---|---|
| Двигаться | ← → или A D |
| Прыжок / двойной прыжок | Пробел, ↑ или W |
| Пауза | P или Esc |
| Достижения | A в меню или паузе |
| Звук вкл/выкл | M |

На тач-экранах появляются кнопки ◀ ▶ ▲.

## Как устроено

- `index.html`, `game.js` — вся игра без зависимостей, Canvas 2D.
- `assets/` — собранные ассеты, `assets_raw/` (не в репозитории) — исходные генерации.
- `tools/build_assets.py` — сборка спрайтов, фонов, иконок, OG-превью и service worker. Запускать после любых изменений ассетов или `game.js`, иначе офлайн-кэш не обновится.
- `tools/build_music.py`, `tools/make_sfx.py` — музыкальные петли и 8-битные эффекты.
- Промпты для генерации ассетов: `assets/README.md`, для музыки: `assets/SOUNDTRACK.md`.
